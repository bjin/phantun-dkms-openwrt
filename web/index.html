kmod-phantun feeds for OpenWrt

Signed apk feeds with the phantun-dkms kernel module for stock OpenWrt firmware (25.12 and later). Built by bjin/phantun-dkms-openwrt.

Router setup

Shell, on the router 
BASE=https://bjin.github.io/phantun-dkms-openwrt
uclient-fetch -O /etc/apk/keys/phantun-openwrt.pem "$BASE/phantun-openwrt.pem"
sha256sum /etc/apk/keys/phantun-openwrt.pem   # must print @PEM_SHA256@
sed -nE "s#^.*/((releases|snapshots)/.*/kmods/[^/]+/packages\.adb)\$#$BASE/\1#p" \
    /etc/apk/repositories.d/distfeeds.list > /etc/apk/repositories.d/phantun.list
apk update && apk add kmod-phantun
insmod phantun managed_local_ports=51820   # parameters: see the phantun-dkms README
  • The module only installs when the router runs exactly a (version, target, kernel) listed below.
  • After every firmware upgrade, regenerate phantun.list with the same command and reinstall.
  • Public key sha256: @PEM_SHA256@
